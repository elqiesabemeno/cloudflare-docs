---
title: Workflows step limit increased to 100,000 steps per instance
description: Each Workflow instance supports 10,000 steps by default, configurable up to 100,000 steps
products:
  - workflows
  - workers
date: 2026-02-20 12:00:00 UTC
---

Each Workflow instance now supports 10,000 steps by default, configurable up to 100,000 steps in your `wrangler.jsonc` file:

```json
{
	"workflows": [
		{
			"name": "my-workflow",
			"binding": "MY_WORKFLOW",
			"class_name": "MyWorkflow",
			"limits": {
				"steps": 50000
			}
		}
	]
}
```

Note that the maximum persisted state limit per Workflow instance remains **100 MB** for Workers Free and **1 GB** for Workers Paid. Refer to [Workflows limits](/workflows/reference/limits/) for more information.
